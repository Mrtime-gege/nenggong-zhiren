# 能工智人 0.6.0 更新说明

日期：2026-11-01
版本：`0.6.0`
定位：面向人工回复团队的人类兜底模型供应商，不是 AI API 中转站。

## 一句话总结

0.6.0 把“能收到请求、能人工回复”的早期工作台，升级成支持**会话化接待、AI 辅助、自动 AI、管理员接管、断线恢复、可观测与安全边界**的完整人工回复平台。

## 核心更新

### 1. 会话化接待

- 同一会话的请求按稳定会话 ID 聚合为一张队列卡。
- 显示轮次、首选回复员和同会话历史。
- 同一会话只允许一个进行中轮次。
- 回复员完成一轮后成为该会话的首选接待人。
- 队列支持“全部 / 待认领 / 进行中 / 最近 / 我的”筛选和会话搜索。

### 2. 断线与重启恢复

- 运行中票据、认领状态、SSE 日志和幂等记录持久化。
- 带 `Idempotency-Key` 的调用方可以在断线或服务重启后重连。
- 调用方主动断开后进入重连宽限期；超时未重连自动取消，不再长期挂着 claimed/streaming 票据。
- 宽限期覆盖 queued、claimed、streaming 三种状态。

### 3. AI 辅助

- AI 结果只进入人工草稿和待发送工具列表，**不自动发送、不执行工具**。
- 原生转发：保留原始 messages、tools、tool_choice、response_format。
- 原生 `tool_calls` 进入人工工具栏；正文中的伪工具标记会被清理。
- 支持回复员主动填写**生成引导提示词**，生成/重新生成时附加给上游。
- AI 生成显示已用时间。
- 收到票据自动 AI：管理员开启后，票据到达即预生成，结果暂存，认领后自动填入。
- 认领后自动 AI：管理员总开关 + 管理员/回复员各自个人开关 + AI 权限共同控制。
- 自动 AI 生成期间锁定坐席输入框、工具编辑和相关发送按钮。
- 支持无人认领超时自动回复。
- 支持 AI 日请求/日 token 限额、全局并发和独立密钥文件。

### 4. 工具与接管

- 工具参数支持 JSON Schema 基础校验：必填、类型、枚举、长度、数值范围和额外字段。
- 新增格式化 JSON、Ctrl+Enter 添加/保存、编辑和移除待发送工具。
- 工具调用始终只返回给调用方，不在本机执行。
- 管理员可以接管其他回复员已认领、尚未开始流式的票据。
- 接管会重置响应超时、取消无人认领自动回复计时、写入交接备注和审计日志。
- 原回复员失去 finish 权限，继续操作返回 403。

### 5. 管理、监控与历史

- 状态页升级为信号核心仪表盘：健康状态、进程指标、存储、队列流、审计信号。
- 新增 Prometheus `/metrics` 和监控告警配置。
- 新增全局历史检索、SQLite FTS5 索引和 CSV 归档。
- 用户管理支持角色、模型权限、功能开关、密码重置和最后管理员保护。
- API Key 支持过期时间、RPM/日/月配额、并发和模型范围。
- 审计覆盖登录、账号、密钥、设置、票据和 AI 操作。
- 新增可公开的 `/guide` 新手教程，管理员可关闭未登录访问。

### 6. 设置与模型

- 设置拆分为“个性化设置”和“管理员功能设置”。
- 设置修改自动保存，数值越界拒绝而不钳制。
- 管理员和回复员都能设置“认领后自动使用 AI”。
- 新增模型级输出速度：`speedMs` 范围 0–60000ms，0 不限速，留空跟随全局。
- 全局默认输出速度可编辑：默认 26ms，范围 0–60000ms。
- 输出速度按流式片段计算，文档提供 100ms ≈ 中文 20 字/秒的参考。

### 7. 存储、附件与安全

- 票据和幂等记录迁移 SQLite `state.db`，历史迁移 `history.db`。
- 启用 WAL、synchronous=NORMAL、busy_timeout。
- 状态快照合并写入；claim/finish 等关键节点同步落盘。
- 票据列表支持轻量 ETag 和已完成摘要缓存。
- 附件支持文本、日志、JSON、CSV、图片和 PDF；危险格式拒绝。
- 图片重编码、PDF 页图 worker 默认按需启用，失败回退。
- 增加每密钥上传配额、请求结构上限、附件总容量预算、审计轮转。
- 只有信任代理的 `X-Forwarded-For` 才参与审计和登录限流。
- 本机文件权限保持 0600。

### 8. 界面与移动端

- 队列按会话合并，长会话默认折叠最近 30 条。
- 新增移动端“队列 / 会话”切换、单行可滚动命令栏和首屏回复框。
- 登录页垂直居中、密码显示/隐藏、移动端尺寸修复。
- 新增项目图标“人类信号”：人形 + 轨道节点 + 在线状态徽标；提供 SVG、ICO、多尺寸 PNG、apple-touch-icon 和 PWA manifest，并接入登录页/工作台/管理页/教程。
- 状态页、设置页、模型页和表格在窄屏下适配。
- 登录页 -> 工作台 -> 设置 -> 状态页完成真实浏览器桌面/移动端冒烟。

## 修复与加固

- 修复操作员设置页缺少自动 AI 开关元素导致整页无法保存。
- 修复 AI 正文尾随 `[tool use: ...]` 和“已调用工具”文本。
- 修复 AI 超时只覆盖响应头、延迟正文可绕过超时的问题。
- 修复全局流式速度为 0 时忽略模型级速度的问题。
- 修复带幂等键的调用方断开后 claimed/streaming 票据长期不结束。
- 修复 AI 结果在认领后到达时不自动补拉完整详情。
- 修复设置成功 toast 在服务端未确认时提前显示。
- 修复会话第二张票据重复入队、移动端顶栏覆盖和回复框掉出首屏。

## 升级注意

- 服务版本仍为 `0.6.0`。
- 旧 `state.json`/journal 会在缺少 `node:sqlite` 时回退；生产建议使用 Node.js 24+。
- 正式部署请使用独立管理员密码、独立调用密钥和 TLS 反代。
- 本版本仍是单进程参考实现，不提供多节点 HA。
