GitHub 登录 进入工作台
HUMAN PROVIDER · 5 分钟上手

有人在后台，替你完成每一次回复。

能工智人是一个兼容 OpenAI 接口的人工回复服务。调用方像调用普通模型一样发请求， 回复员在工作台里认领、阅读并写出结果，调用方收到标准格式的回复。

重要：这是人工回复工作台，不是 AI API 中转站、模型代充或自动回复服务。AI 辅助只给回复员提供建议。

打开工作台 我是调用方 我是回复员 GitHub 项目
01

调用方发请求

用 OpenAI SDK、curl 或任意兼容客户端，把请求发到 /v1/chat/completions。

02

回复员认领

工作台队列出现票据。认领后阅读上下文，选择思考、正文或直接完成。

03

调用方拿到结果

回复按 OpenAI 格式返回；流式请求会逐段推送，客户端体验与普通模型一致。

CALLER

给调用方

只需要三样东西：服务地址、API Key、模型名。

连接信息

API Base
由管理员提供，格式为 http://<服务地址>/v1
接口
/chat/completions
模型
使用管理员分配的模型名
认证
Authorization: Bearer <你的 API Key>

安全提醒

  • API Key 只放在服务端或本地环境变量，不要写进前端代码。
  • 不要截图或粘贴完整 Key 到聊天、工单和公开仓库。
  • Key 泄露时，请管理员立即撤销并重新生成。

最小可用 curl

curl "$ZHIREN_BASE_URL/chat/completions" \
  -H "Authorization: Bearer $ZHIREN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "<模型名>",
    "messages": [
      { "role": "user", "content": "你好，请介绍一下自己" }
    ],
    "stream": true
  }'

把 ZHIREN_BASE_URL 和模型名换成管理员给你的实际值。普通 JSON 请求把 stream 改成 false。

OPERATOR

给回复员

登录后大部分时间只需要做三件事：认领、阅读、回复。

  1. 登录工作台 打开 /console，使用管理员分配的账号登录。左侧是队列，中间是会话，底部是回复编辑区。
  2. 认领票据 点击票据或按「下一张」；队列会显示待认领、进行中、最近结束。认领只代表获得当前编辑权，可以放回队列或转交。
  3. 阅读会话 中间时间线按顺序显示调用方消息、上下文、已发送思考/正文和工具调用；不再把它们拆成两个独立区域。
  4. 用右侧上下文处理工具 右侧「资料 / 工具 / AI / 备注」提供客户信息、工具参数、AI 建议、标签、优先级和内部备注。
  5. 调整高度并清空 拖动回复编辑区上方的横向分隔线调整高度；双击恢复默认。「清空」会一次性清除草稿、AI 建议和待发送工具。
  6. 使用全局预览定位 会话右侧是代码编辑器式全局预览：点击或拖动预览条可以快速跳到会话不同位置，原生滚动条已隐藏；长会话超过加载上限时，预览顶部会显示「更早 N 条」。
  7. 用命令面板提速 按 Ctrl/Cmd+K 搜索票据或执行认领、AI、工具、备注、完成等操作；顶栏还能收起队列、命令面板可切换紧凑密度。
  8. 发送并完成 使用「思考」「正文」或「完成」发送；流式请求会立即推送。完成后票据进入「最近结束」。

快捷键

  • 下一张AltJ
  • 发送思考CtrlEnter
  • 发送正文ShiftEnter
  • 正文并完成CtrlShiftEnter
  • 放回队列AltB

小提示

  • 草稿会自动保存在当前浏览器，刷新或切走再回来不会丢。
  • 消息旁的「引用」会把原文带进回复框，适合逐条回应。
  • 工具续跑票据请先看工具结果，再决定继续调用还是直接回复。
  • 不确定时先发「思考」，确认方向后再发送正文。
ADMIN

给管理员

第一次部署时，按这个顺序配置即可。

1. 账号

在「用户管理」创建回复员账号，分配角色和可用模型。

2. 模型

在「模型」确认对外模型和权限；回复员只能看到被授权的模型。

3. API Key

在「API 密钥」为调用方生成 Key，设置并发和用量限制。

运行状态、历史记录和审计在顶部对应页面查看；「设置」按左侧分类切换：个性化、运行参数、功能开关、AI 辅助、安全和系统信息。只有管理员能看到管理员分类。

FAQ

常见问题

调用方断开了怎么办？

票据可能标记为「调用方已断开」。可以先处理完；若请求已不可达，使用放回、拒绝或取消。

为什么看不到某个模型？

模型可见性由管理员在用户或模型设置中控制。联系管理员确认账号权限。

流式回复为什么没有马上结束？

流式票据需要回复员发送正文或完成。只发「思考」不会结束请求。

忘记密码怎么办？

联系管理员在「用户管理」中重置密码；不要通过聊天发送新密码。
